# GigaDictate

Голосовой ввод для Windows в любом поле ввода: в браузере, мессенджерах, Word, IDE или блокноте. Речь распознаёт **GigaAM v3** от Сбера. Программа работает полностью офлайн, звук никуда не отправляется.

## Установка

Скачайте `GigaDictate-Setup-<версия>.exe` со страницы релизов и запустите. Права администратора не нужны: программа ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\GigaDictate`. Мастер установки по шагам покажет, куда ставится программа и что будет сделано. Он предложит включить автозапуск и значок на рабочем столе, а в конце сразу запустит GigaDictate. Модель распознавания уже внутри установщика, интернет не нужен.

Чтобы обновить программу, запустите установщик новой версии: настройки сохранятся. Удаляется программа через «Параметры → Приложения». При удалении можно также стереть настройки.

Если устанавливать не хочется, есть архив `…-portable-windows-x64.zip`: распакуйте его и запустите `GigaDictate\GigaDictate.exe`.

## Как пользоваться

1. После установки GigaDictate запускается сам. Если нет, найдите его в меню «Пуск». В области уведомлений, возле часов, появится значок микрофона.
2. Поставьте курсор в любое поле ввода.
3. Нажмите **Правый Ctrl**:
   * **удерживайте**, пока говорите, и отпустите, когда закончите (push-to-talk);
   * **или нажмите один раз**, чтобы начать, и ещё раз, чтобы закончить.
4. Текст появится там, где стоит курсор: с пунктуацией и заглавными буквами, числа будут записаны цифрами («в 15:30»).

| Действие | Как |
|---|---|
| Отменить запись | `Esc` |
| Перенос строки | скажите «новая строка» или «с новой строки» |
| Новый абзац | скажите «новый абзац» |
| Настройки | правый щелчок по значку в трее |

После открытия микрофона звучит восходящий сигнал. Во время речи над нижним краем экрана появляется черновик. Он обновляется примерно раз в две секунды и может уточняться. После остановки в поле ввода попадает окончательный текст.

При включённых голосовых командах произнесите «запятая», «точка», «точка с запятой», «двоеточие», «тире», «многоточие», «вопросительный знак» или «восклицательный знак». Чтобы продиктовать эти слова буквально, отключите голосовые команды в трее.

Цвет значка показывает состояние: серо-синий — готов, красный — идёт запись, оранжевый — распознаю.

## Настройки (меню в трее)

* **Изменить горячую клавишу…**: нажмите нужное сочетание, например `F9`, `Ctrl+Win` или `Ctrl+Alt+D`. Сочетания, которые мешают обычному набору (буквы, Shift+буква, Ctrl+Shift — переключение раскладки), программа не примет.
* **Модель**: RNNT (точнее) или CTC (быстрее). Обе ставят пунктуацию.
* **Способ вставки**: автоматически, печать символов или через буфер обмена. В автоматическом режиме короткий текст печатается, длинный вставляется через Ctrl+V, после чего ваш буфер обмена восстанавливается.
* Звуковые сигналы, голосовые команды, пробел после текста, освобождение памяти при простое, автозапуск.

Файл настроек `%APPDATA%\GigaDictate\config.json` можно править вручную. Ошибочные значения программа заменит значениями по умолчанию и сообщит об этом. Там же лежит журнал `gigadictate.log`. Распознанный текст в журнал не пишется. Текст, оставленный в буфере обмена (когда напечатать не удалось), не отправляется в облачный буфер Windows.

## Ресурсы

* Программа занимает ~100 МБ, модель — 216 МБ (int8).
* В простое процессор не используется. Микрофон открывается только во время записи.
* Модель загружается при первой диктовке и через 10 минут простоя выгружается из памяти. Повторная загрузка занимает меньше секунды и идёт, пока вы говорите.
* Длинная диктовка распознаётся по кускам прямо во время речи (нарезка по паузам), поэтому после отпускания клавиши остаётся обработать только последние секунды.

## Известные ограничения Windows

* **Окна, запущенные от администратора** (например, диспетчер задач или терминал «от имени администратора»), не принимают ввод от обычных программ. В этом случае текст попадёт в буфер обмена, а программа покажет уведомление. Вставьте его через Ctrl+V. Запускать GigaDictate от администратора не нужно и не рекомендуется: процесс с повышенными правами читал бы настройки и модель из папки, которую может изменить любая обычная программа.
* Если пока шло распознавание вы переключились в другое окно, текст не будет напечатан «не туда»: он окажется в буфере обмена.
* Если пришла полная тишина, проверьте *Параметры → Конфиденциальность → Микрофон → Разрешить классическим приложениям*.

## Разработка

```bash
pip install -r requirements-dev.txt
python scripts/fetch_models.py
python -m pytest tests            # на Windows также сквозные тесты с настоящим окном
python -m gigadictate             # запуск из исходников
python scripts/make_ico.py && python -m PyInstaller GigaDictate.spec
# установщик (Windows, Inno Setup 6): ISCC /DAppVersion=1.0.1 installer\GigaDictate.iss
```

CI (`.github/workflows/windows.yml`) на каждом push прогоняет тесты на Windows, собирает exe, повторяет сквозной тест на собранном exe, затем собирает установщик и проверяет его: тихая установка, переустановка поверх, сквозной тест установленной программы, удаление без следов. При метке `v*` публикуется релиз с установщиком и портативным архивом.

Модели: [GigaAM](https://github.com/salute-developers/GigaAM) (MIT), ONNX-версия — [istupakov/gigaam-v3-onnx](https://huggingface.co/istupakov/gigaam-v3-onnx), запуск — [onnx-asr](https://github.com/istupakov/onnx-asr).
